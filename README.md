# YouTube UX Portfolio

A unified Streamlit portfolio for three independent product concepts: accessible Shorts, creator analytics, and Smart TV discovery.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Evidence and prototype scope

The three linked prototypes use synthetic demo content. They are design concepts rather than production integrations. This portfolio deliberately distinguishes design rationale and proposed validation from research and usability testing that has not yet been conducted.

## Figma

The Figma connector must be connected to create an editable Figma design file. This repository contains the portfolio site and documented case studies; it is not a Figma file.
